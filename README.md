# Neon Snake 🐍✨

Змейка для iOS в неоновом стиле на SwiftUI.

## Фичи
- **Плавное движение**: змейка рисуется в `Canvas` каждый кадр и интерполируется между клетками, а не прыгает.
- **Неоновая графика**: свечение, градиентное тело-трубка с бликом, глаза смотрят по направлению движения, язычок.
- **Эффекты**: взрывы частиц при поедании, всплывающие «+1», тряска экрана и вспышка при столкновении.
- **Бонусная звезда** (+5) появляется после каждого 5-го фрукта, вокруг неё кольцо-таймер.
- **Скорость** растёт с каждым фруктом.
- **3 темы**: Неон, Закат, Океан.
- **Хаптика**, рекорд сохраняется, пауза при сворачивании приложения.
- **Управление**: свайпы в любом месте экрана (за один свайп можно сделать несколько поворотов), а в симуляторе — стрелки и пробел.

## Запуск
1. Нужен Mac с **Xcode 16+**, iOS 17+.
2. Открой `NeonSnake.xcodeproj`.
3. Выбери симулятор iPhone и нажми ▶︎ (⌘R).
4. Для запуска на своём iPhone: в **Signing & Capabilities** выбери свою команду (Personal Team) и при необходимости поменяй Bundle Identifier.

## Структура
```
NeonSnake/
├── NeonSnakeApp.swift          — точка входа
├── Game/
│   ├── SnakeEngine.swift       — чистая логика игры (сетка, ходы, столкновения, бонусы)
│   ├── GameModel.swift         — игровой цикл, фазы, частицы, рекорд
│   └── Theme.swift             — цветовые темы
├── Rendering/
│   └── SnakeRenderer.swift     — отрисовка змейки, фруктов и звезды
└── Views/
    ├── ContentView.swift       — корневой экран
    ├── MenuView.swift          — меню с анимированной змейкой и выбором темы
    ├── GameScreen.swift        — экран игры, HUD, управление
    ├── BoardView.swift         — игровое поле
    ├── BackgroundView.swift    — анимированный фон
    └── Components.swift        — кнопки, оверлеи паузы и Game Over
```

CI в `.github/workflows/ios-build.yml` собирает проект на macOS при каждом пуше.
